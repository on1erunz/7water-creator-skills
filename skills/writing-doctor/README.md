# Writing Doctor｜保留作者声音的中文修稿

`writing-doctor` 用于已有草稿。它先找出稿件真正要表达的判断，再检查标题让读者期待什么、开头为何留人、正文有没有给出理由和证据；修改时尽量保留作者原本的语气与立场。

**你可以提供：**草稿、标题、发布形式，以及想保留的句子或允许修改的范围。

**你会得到：**按重要性排序的具体诊断；需要改稿时，先给修订稿，再说明关键改动和仍待核实的事实。

**示例：**“使用 `$writing-doctor` 检查这篇文章的开头是否承诺过多，只改影响读者理解的地方，保留我的语气。”

它不会替你添加固定频道介绍、虚构经历或套用统一的爆款句式。只有一句选题、还没有草稿时，用 `topic-to-outline`。
