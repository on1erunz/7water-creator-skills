# Writing Doctor｜保留原声的中文修稿

针对已有草稿，先保住作者的中心判断、情绪温度与有味道的原句，再检查标题承诺、开头留人、正文证据、读者理解顺序、口播节奏与互动结尾。

保留原版强约束：禁用模板对照句并用脚本扫描；原文语言默认只改 20% 以内；理论补充单独计算；用户点名的真实锚点不得静默删除；短视频分章节；复核证据、人味、事实边界和语气。脚本见 [`scripts/lint_draft.py`](scripts/lint_draft.py)。

开始时从 `7wc` 底稿或[频道配置模板](references/channel-profile.md)读取领域、立场、资料、语气和固定表达。固定介绍、四件套 CTA、Notion 或本地归档由作者自己指定。

示例：`使用 $writing-doctor：这是草稿。保留我的判断和语气，只修标题与开头的错位，理论补充另列。`
