# Topic to Outline｜带理论与资料的选题研究简报

把一句题目变成可研究、可写作的内容简报。保留原版流程：冻结原始种子、拆概念、提出 3—6 个研究目标、筛选来源、区分事实与解释、做 HKR 检查、设计 hook、互动与结构，最后判断由作者写、AI 起稿还是人机混合。

研究前先了解创作者的内容领域、理论和思想立场、目标读者与所需来源。需要行业研报时检查发布者利益、样本、口径与日期，并尽量用原始数据核对。小说、留学、就业、女性成长等只是[领域研究地图](references/domain-research-map.md)里的示范；遇到任何新领域，按问题类型、理论分歧、证据层级和来源审查建立专属研究地图。

原版详尽的人文社科理论库保留在 [`SKILL.md`](SKILL.md)，包含哲学、逻辑、社会学、性别与传播学视角。每次选 1—3 个真正参与论证的理论，不能用学者名装饰稿件。

示例：`使用 $topic-to-outline：把“应届生为什么难进某行业”做成简报。比较劳动力市场分割与信号理论，找官方就业数据和行业研报。`
