# Topic to Outline｜从一句想法到内容简报

`topic-to-outline` 适合已经有一个话题、却还没有完整草稿的创作者。它保留你的原始想法，拆开模糊词，判断中心观点与证据是否足够，再提出读者入口、开头方向和论证顺序。

**你可以提供：**一句题目或观点；如果已有目标读者、亲历材料、平台与时长，也一并提供。

**你会得到：**题目判断、可查问题、证据缺口、开头方向和一份能继续写作的简报。题目尚不成立时，它会说明应该怎样收窄。

**示例：**“使用 `$topic-to-outline`，把‘为什么大家都想做个人 IP’整理成适合刚开始做内容的人的短视频简报。”

这个 Skill 默认只做到简报。已有草稿需要修改时，用 `writing-doctor`。
