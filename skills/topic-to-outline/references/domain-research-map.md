# 按领域选择理论、立场与资料

先问用户在讲什么、站在什么位置、希望回应谁。下表的商业、人文、就业、小说、留学、女性成长等**仅是示范，不是领域清单或适用范围限制**。遇到教育、科技、艺术、游戏、体育、医疗、法律、地方生活或任何其他领域，先用下面的通用方法建立该领域的理论与资料地图，再选真正能解释题目的视角。不要依据创作者的领域自动推断其意识形态。每条内容通常只选 1—3 个视角；若视角之间有分歧，指出分歧和各自解释不了的部分。理论名称不能代替事实证据。

研究开始前，把用户的回答写成一句任务说明：`为【具体读者】解释【具体问题】，优先从【理论/立场】看，需核实【事实】，优先找【资料类型】，避开【不接受的表达】。`

## 任何新领域都按这六步建立地图

1. **问题类型**：这是事实描述、机制解释、价值争论、方法教学、创作表达，还是交易/决策建议？同一领域的不同问题，资料体系可能完全不同。
2. **理论与意识形态**：问作者偏好的思想传统、竞争视角、价值前提和不接受的说法。没有答案时提出两三个**可供选择**的不同视角，分别说明会强调什么、忽略什么，不能替作者站队。
3. **领域知识**：找该领域的一手概念、基础模型、经典争论、行业术语与代表性原作。区分学术理论、行业经验、规范性主张和创作者自己的判断。
4. **证据层级**：依题目寻找原始研究、官方数据与规则、行业研报、机构披露、作品原文、访谈、实物或亲历。先确认哪一种资料有资格支持哪一种主张。
5. **来源审查**：记下作者/机构、年份、地区、样本、方法、利益关系和适用边界。关键结论尽量交叉核对；没有证据时写待查问题。
6. **输出研究卡**：列出中心问题、候选理论及分歧、需查的原始来源、可用案例、反例和写作边界。只要能回答本题，无须把领域知识大全塞进简报。

## 使用方法

1. 先把大领域收窄成一个可回答的问题，例如“某城市应届生为何进入某行业难”，而不是“年轻人就业怎么了”。
2. 记录创作者的立场：描述事实、解释机制、提出规范性判断，这三层分别写。用户没有立场时给两种有区别的可选视角，请其选择或允许并列。
3. 提出 3—6 个研究问题。对每个问题写明优先来源和判断证据质量的办法。行业研报可提供市场观察，但要查发布者利益、样本、定义和统计方法；优先用原始数据核对关键数字。
4. 选 1—3 个理论。每个理论都写“白话解释—它看见什么—题中可观察的证据—它解释不了什么”。不得只列学者名单。
5. 如果用户要最新行业、政策、学校或就业信息，查当期原始来源并标注日期。查不到时保留未知，不编数字或引用。
6. 交付给写作环节时附上：中心判断、反方解释、事实证据、理论解释、价值立场、来源链接、尚待核实处。
