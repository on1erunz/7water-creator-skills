# 创作者研究与表达底稿

首次从 `7wc` 启动整套工作流时，邀请用户用自己的话粗略说明；已有信息沿用，未知项写“待定”。这份底稿用于选择理论、资料和表达规则，不是强制填表或公开档案。单独调用某个子技能时，只追问影响当前任务的缺项。

```markdown
# 创作者配置
- 内容主题与边界：
- 目标读者的具体处境：
- 常见问题、正在争论的命题：
- 偏好的理论、思想传统或意识形态视角：
- 排斥的立场、论证方式或理论误用：
- 需要的资料类型（行业研报、学术论文、官方统计、政策、访谈、亲历、文学文本等）：
- 已有可信来源、研究报告、案例与一手材料：
- 平台与内容形式：
- 作者希望保留的表达习惯：
- 作者不接受的表达或材料：
- 固定频道介绍、结尾口播与修改幅度（如有）：
- 可用经历、案例与证据：
- 商业目标或行动目标（可选）：
```

配置记录的是可修正的约束。用户本轮说明与旧配置冲突时，以本轮说明为准。不要从年龄、职业标签直接推断需求，也不要把个人风格压缩成固定口头禅或 CTA。涉及多领域时，按具体选题切换理论与来源；示范领域不能限制创作者的题材。不要把某一派思想当成默认正确答案。
