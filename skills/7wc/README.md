# 7WC · 7water Creator

`7wc` 是创作者的内容决策工作流。它先判断你当前的问题是概念不清、选题不稳、对标看不懂、证据不足，还是发布后不知道怎么复盘，再只完成最需要的一步。

**你可以提供：**一句想法、一篇参考作品、一个待做选题、一组资料，或已发布内容及反馈。

**你会得到：**一个更具体的问题、支撑当前判断的材料与限制，以及下一步可执行的决定。资料不足时，它会明确指出缺什么。

**示例：**“使用 `$7wc`，我想写‘AI 让普通人更自由’，先帮我判断这个题实际要讨论什么。”

`7wc` 不默认替你写全文。已有草稿要逐句修改时，用 `writing-doctor`；需要把一句题目展开为简报时，用 `topic-to-outline`。
