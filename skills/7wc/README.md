# 7wc · 7water Creator

`7wc` 是整套 `7water-creator-skills` 的总工作台。首次使用先粗略了解你的内容领域、具体读者、理论/意识形态视角、所需资料和表达习惯；随后判断当前是概念不清、选题不稳、对标看不懂、证据不足，还是需要发布复盘，并完成最需要的一步。

**你可以提供：**一句想法、一篇参考作品、一个待做选题、一组资料，或已发布内容及反馈。领域、思想立场和资料需求说个大概就够了，不确定可以写“待定”。商业、文学、科技、教育等任何题材都可用；[领域示范](../topic-to-outline/references/domain-research-map.md)只是例子。

**你会得到：**一个更具体的问题、支撑当前判断的材料与限制，以及下一步可执行的决定。资料不足时，它会明确指出缺什么。

**示例：**“使用 `$7wc`，我想写‘AI 让普通人更自由’，先帮我判断这个题实际要讨论什么。”

`7wc` 不默认替你写全文。已有草稿要逐句修改时，用 `writing-doctor`；需要把一句题目展开为简报时，用 `topic-to-outline`；需要用已选图片做封面时，用 `cover-maker`。
