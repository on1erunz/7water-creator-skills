# 7WC Creator Skills｜中文创作者的三个通用 Skill

**7WC = 7water Creator。** 这套开源 Skill 帮创作者处理三个常见时刻：还没想清要写什么、已有题目需要形成简报、已经写出草稿需要修改。它们可以独立使用，无需按固定顺序走完。

| Skill | 中文介绍 | 适合什么时候用 |
| --- | --- | --- |
| [`7wc`](skills/7wc/README.md) | 内容决策工作台：澄清问题、判断选题、拆解对标、研究证据、复盘发布反馈。 | 你有想法或材料，但还不确定下一步该做什么。 |
| [`topic-to-outline`](skills/topic-to-outline/README.md) | 选题简报生成器：把一句模糊想法变成面向具体读者、可研究和可写作的内容简报。 | 已有一个话题，尚无完整草稿。 |
| [`writing-doctor`](skills/writing-doctor/README.md) | 中文稿件编辑：检查标题、开头、正文是否互相兑现，定位跳步与证据缺口，按作者要求修改。 | 已经有草稿，想诊断或修订。 |

## 快速使用

将所需的 `skills/<名称>/` 整个目录复制到你的 Agent 所支持的 Skill 目录中，保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。然后用自然语言说明任务，也可显式调用：

```text
使用 $7wc：我有一篇关于自由职业的想法，但还没想清这篇具体要讨论什么。
使用 $topic-to-outline：把“为什么年轻人害怕开始自己的小业务”做成内容简报。
使用 $writing-doctor：检查这篇草稿的标题、开头和正文是否讲的是同一个问题，保留我的语气。
```

## 设计边界

- 三个 Skill 默认不假定你的年龄、平台、账号定位、频道介绍、商业模式或保存目录。
- 研究时区分事实、解释与作者判断；缺少材料时说明缺口，不生成假经历、假用户反馈或假数据。
- 标题、开头、行动引导和修改幅度由具体内容及你的要求决定。
- `7wc` 的重点是决定当前任务；`topic-to-outline` 负责未成稿选题；`writing-doctor` 负责已有草稿。
- 读者理解、内容传播和商业成交需要各自的证据，任何一个 Skill 都不承诺涨粉或收入。

这是一版从个人工作流中抽出的**通用版**。个人账号的固定开场、本地磁盘路径、默认写法比例和强制句式限制没有进入本仓库。本仓库不包含用户私有配置；如需个性化，请在单次请求中提供，或参考 [`skills/7wc/references/creator-profile.md`](skills/7wc/references/creator-profile.md) 在自己的私有工作区另建配置。
